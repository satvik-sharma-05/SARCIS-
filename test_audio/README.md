# Test Audio Files

Place your test audio files in this directory.

## Supported Formats

- `.wav` - Waveform Audio File Format
- `.mp3` - MPEG Audio Layer III
- `.m4a` - MPEG-4 Audio

## Sample Audio Sources

You can get free test audio from:

1. **Your own recordings** - Record test conversations
2. **Free audio libraries**:
   - https://freesound.org/
   - https://www.zapsplat.com/
   - https://www.soundjay.com/

## Testing Tips

1. Start with short audio files (< 1 minute)
2. Test different languages (English, Hindi)
3. Include various scenarios:
   - Customer complaints
   - Technical support calls
   - General inquiries
   - Urgent requests

## Example Test Cases

- `complaint.wav` - Customer complaint scenario
- `urgent.mp3` - Urgent request
- `technical.m4a` - Technical support call
- `general.wav` - General inquiry

## Note

Audio files are ignored by git (see `.gitignore`).
